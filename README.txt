U613 «Циферблат» (Luv Face) для Amazfit Bip Max — версия 0.2.0 (прототип: цвета полосок из общей памяти часов)

ЧТО ЭТО
Отдельный проект (циферблат, не приложение). Чёрный экран без часов, разделён примерно пополам:
  Верхняя половина — две полоски статистики без подписей, у каждой три сегмента: месяц / неделя / день (слева направо).
    Верхняя — слова. Цвета те же, что у поля слов на телефоне (красный -> оранжевый -> жёлтый -> салатовый -> зелёный), сегмента «всего» нет.
    Нижняя — общая статистика (все занятия), тоже месяц / неделя / день.
    Цвета обоих полосок циферблат берёт из общей памяти часов (туда их кладёт приложение Luv Sync). Нет данных — серый.
    ПРОТОТИП: пока Luv Sync пишет придуманные цвета, они меняются с каждой записью. Настоящие цвета от телефона — следующий шаг.
  Нижняя половина — три большие кнопки 🥗 🩸 🧩.
    🩸 открывает приложение «Таймер» (U613, то, что уже стоит на часах). 🥗 и 🧩 пока ничего не делают.
Приложения «Таймер» (U613-timer-v15) и LuvU613 (телефон) этот проект не трогает и не меняет.

КАК УСТАНОВИТЬ (так же, как приложение часов)
1. Создайте НОВЫЙ репозиторий на GitHub и загрузите в него ВСЁ из этой папки (Add file -> Upload files). Скрытых папок в архиве нет.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Settings -> Pages: включите публикацию из ветки gh-pages (как делали раньше). Вкладка Actions: дождаться зелёной галочки
   (если первый запуск прошёл до включения Pages — запустите ещё раз: Actions -> Run workflow).
3. QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Циферблат появится в списке циферблатов часов (долгое нажатие на текущий циферблат -> листать в конец списка) —
   выберите его.

ЧТО ПРОВЕРИТЬ ПЕРВЫМ ДЕЛОМ
- Открывается ли «Таймер» по нажатию на 🩸. Если нет — под полосками, на границе половин, появится короткая красная надпись
  с причиной; пришлите её текст.
- Не съехала ли раскладка вправо/влево (см. ниже, AREA_X).

ИСПРАВЛЕНО В 0.1.2: циферблат полностью отделён от приложения «Таймер» — другое название (Luv Face), другой идентификатор (1072511), другой vender (luvface), другая иконка.
  Раньше у них совпадали vender и иконка, а названия начинались одинаково (U613), и Zepp в режиме разработчика мог принять их за одно приложение.
  Если циферблат от версии 0.1.1 остался в списке, удалите его вручную: он теперь отдельная запись.

ИСПРАВЛЕНО В 0.1.1: добавлен app.js (без него сборка падала с ошибкой «The app.js file must be included in the project»).

ГДЕ ЧТО МЕНЯТЬ
shared/layout.js:
  AREA_X, AREA_W      — горизонтальная полоса, в которой стоят полоски и кнопки (8 и 380: та же сетка, что на главном экране приложения «Таймер»).
                        Если на циферблате всё смещено — меняйте AREA_X (центр экрана для 432 px: AREA_X = 26).
  STRIP_H, STRIP_GAP  — высота полоски и расстояние между ними.
  SEG_GAP             — чёрный зазор между сегментами (3). 0 — сплошная полоска, как на телефоне.
  STRIPS_DY, BTN_DY   — сдвиг блока полосок / ряда кнопок вверх (минус) или вниз (плюс).
shared/colors.js       — палитра (как в приложении на телефоне) и цвет серой заглушки (GRAY).
watchface/index.js     — TIMER_APP_ID / TIMER_APP_URL (что открывает 🩸), SYNC_APP_ID (Luv Sync), SYNC_GUARD_MS (защита от зацикливания),
                        DEBUG (строка проверки под полосками; в готовой версии поставить false).
shared/link.js         — ключи общей памяти и формат записи цветов (такой же файл лежит в проекте Luv Sync).

ЧТО НОВОГО В 0.2.0
- Циферблат красит шесть сегментов цветами из общей памяти часов (hmFS.SysProGetChars, ключ luv_c).
- Каждый раз, когда циферблат снова оказывается на экране (включили экран, вышли из приложения), он перекрашивает сегменты и
  запускает приложение Luv Sync (оно записывает свежие цвета и само возвращает на циферблат). Чаще, чем раз в 15 секунд, запуск
  не делается — это защита от зацикливания (Luv Sync, закончив, возвращает на циферблат, и это снова «возвращение»).
- Под полосками серая строка проверки: n=<номер записи> res=<сколько раз циферблат оказывался на экране> age=<сколько секунд назад записаны цвета> <статус>.
  Статусы: sync:go — запуск Luv Sync отправлен, wait — защита от зацикливания, noSysPro — у циферблата нет общей памяти,
  sync:fail — запуск не удался (причина красной надписью), noDelegate — платформа не сообщает о возвращении на экран.

ЧТО ПРОВЕРЯТЬ (порядок)
1. Сначала поставьте Luv Sync (отдельный архив LuvSync-v1.zip, инструкция в нём), откройте его вручную из списка приложений.
   Должно быть: шесть цветных квадратов и «Готово. Запись № 1».
2. Поставьте этот циферблат и выберите его. Полоски должны стать теми же цветами, что были квадраты.
3. Выключите и включите экран. Ожидается: на секунду мелькнёт Luv Sync, вернётся циферблат, n в строке проверки вырос, цвета другие.
Что прислать: что написано в строке проверки; мелькает ли Luv Sync; возвращается ли сам; обновляются ли цвета.

ТЕСТЫ (необязательно): npm test — проверяют палитру, раскладку и прогон циферблата на заглушках API часов.
